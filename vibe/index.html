雰囲気カウンター

プライバシーポリシー / サポート（Vibe Counter）

雰囲気カウンター（英語名 Vibe Counter）は、撮影した写真から受ける雰囲気・ムードを AIが読み取り、エンターテインメントとして「Vibe」を表示するアプリです。 人物の容姿・魅力・身体的特徴を評価する機能はありません。

プライバシーポリシー

1. 撮影画像の取り扱い

  • ローカルGemmaモード：撮影画像・プロンプト・解析結果は端末内でのみ処理され、外部へ送信されません。
  • Gemini APIモード：撮影画像はユーザー自身のAPIキーを用いてGoogleのGemini APIへ送信されます。開発者のサーバーには送信されません。
  • お試しモード：AIを使用しません。撮影画像は解析されず、外部へも送信されません。

2. 通信を行う場面

本アプリが通信するのは次の場合だけです。いずれも、本ポリシーへの同意後、ユーザーの操作をきっかけとして行われます。

  • ローカルAIモデルのダウンロード（配布サーバーへの接続）
  • Gemini APIモードでの解析（Google の Gemini API への送信）

3. 保存されるデータ

  • Gemini APIキーは端末内のセキュアストレージ（iOS: Keychain / Android: Keystore連携）にのみ保存されます。
  • ダウンロードしたAIモデルファイルはアプリ専用領域に保存されます。
  • 撮影画像は自動保存されません。結果画像の保存・共有はユーザーの操作によってのみ行われます。
  • 本ポリシーに同意した日時と版を端末内に記録します。

4. 収集しないデータ

  • アクセス解析・クラッシュレポートの目的で個人情報を収集しません。
  • 解析履歴をクラウドへ保存しません。
  • 開発者のサーバーへ撮影画像を送信することはありません。
  • 広告の配信・トラッキングを行いません。

5. お問い合わせ

本ポリシーに関するお問い合わせは kumi0708@hotmail.com までお願いします。

サポート

よくある質問

AIモデルのダウンロードが終わりません
モデルは約2.6GBあります。Wi-Fi環境で、画面を開いたままお試しください。中断しても、次回は途中から再開します。

結果が出ない・エラーになる
端末の空きメモリが不足していることがあります。他のアプリを終了してからもう一度お試しください。設定から「お試しモード」に切り替えると、AIを使わずに動作を確認できます。

写真はどこかへ送られますか
ローカルGemmaモードとお試しモードでは送信されません。Gemini APIモードのときだけ、ご自身のAPIキーでGoogleのGemini APIへ送信されます。

結果の「Vibe」は何を見ていますか
表情・ポーズ・服装のスタイル・構図・光・色など、写真から視覚的に確認できる情報だけを手がかりにしています。人物の容姿や魅力を評価するものではなく、点数もつけません。
